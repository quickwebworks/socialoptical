# Second homepage Google Ad Manager ad

Open /admin/ and choose Advertisements → Homepage ad 2 — below first ad.
Select Google Ad Manager, paste its header and body tags, validate, enable the placement, choose the dates and Save advertisement. Both tags must define a 300 × 250 slot. The new position sits 24px below the first homepage ad and has separate saved settings.

It is initially configured with the first ad’s current campaign and schedule. Replace only the second placement’s tags to use a different campaign. Google may return no fill; disabled or expired ads remain hidden.

Existing database: run database/second-homepage-ad.sql. Existing security policies and admin-only tag storage remain in effect.
